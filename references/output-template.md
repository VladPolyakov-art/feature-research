# Output template: `research/feature-<slug>.md`

Copy the structure below. Keep every section; if a section has no data, write what you looked for and that nothing was found. Replace the bracketed hints.

The header block, the Sources list and the tag legend follow the kit protocol (`kit-protocol.md`, sections 2 and 3). Copy the legend into the file too, so a reader outside the conversation understands it.

---
